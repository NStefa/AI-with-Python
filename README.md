## Pobieranie repozytorium

### Opcja 1 - klonowanie repozytorium

Upewnij się, że masz zainstalowanego [Gita](https://git-scm.com/downloads), a następnie wykonaj w terminalu:

```bash

git clone https://github.com/NStefa/AI-with-Python.git

cd AI-with-Python

```

### Opcja 2 - pobieranie jako ZIP

Kliknij zielony przycisk **Code** → **Download ZIP** na stronie repozytorium, a następnie rozpakuj archiwum.

---

## Uruchomienie notatnika

### Opcja 1 – Google Colab

Nie wymaga żadnej instalacji - wystarczy konto Google.

1. Wejdź na [colab.research.google.com](https://colab.research.google.com)

2. Wybierz **File → Upload notebook**

3. Wgraj plik odpowiedni plik `.ipynb`

### Opcja 2 – VS Code

1. Pobierz i zainstaluj [VS Code](https://code.visualstudio.com/)

2. Zainstaluj rozszerzenie **Python** oraz **Jupyter** (zakładka Extensions → wyszukaj nazwę)

3. Upewnij się, że masz zainstalowanego [Pythona](https://www.python.org/downloads/) (wersja 3.10 lub nowsza)

4. Otwórz folder z repozytorium: **File → Open Folder**

## Wymagane biblioteki

Notatnik (na ten moment) korzysta wyłącznie z bibliotek wbudowanych w Pythona - **nie trzeba instalować żadnych dodatkowych pakietów**.

W kolejnych materiałach pojawią się biblioteki zewnętrzne (NumPy, Pandas, PyTorch). Instrukcja instalacji znajdzie się w osobnym pliku `requirements.txt`.
